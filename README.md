# skadedyrguiden
## Bilder (Gemini)
Bildene lages av `.github/workflows/images.yml` med Gemini/Imagen fra `scripts/images.json`
(krever secret `GEMINI_API_KEY`). Den kjører når `images.json` endres og lager bare manglende bilder.
Kjør den manuelt fra Actions-fanen; skriv navn (f.eks. `hero mus`) for å lage bilder på nytt.
